## MODULE SPECIFICATIONS

### **01. HALT Triage**
* **Function:** Prevents "autopilot" navigation by requiring logical validation.
* **Logic Pool:** Randomized checks including Physiology (HALT), Pattern Recognition, and Basic Math.
* **Goal:** Re-engages executive function through high-load processing.

### **02. Ocular Sweep (The Teal Feather)**
* **Technique:** Advanced EMDR with Saccadic tracking.
* **Visuals:** A Neon Teal Feather following a 2.0s "Wavy" (Figure-Eight) path.
* **Anchoring:** Features a **Fixed Horizontal Baseline** and periodic **Numerical Cognitive Anchors** (number flashes) to prevent mental drift.

### **03. White Surge (Spark)**
* **Technique:** Visual Tension & Release.
* **Action:** A central thought object undergoes a 2-second "Charge" (shrinking and glowing) before a centrifugal 720-degree spinning explosion into Teal and White shards.

### **04. Axial Stabilize (Weave)**
* **Technique:** Optokinetic Nystagmus (OKN) & Visual Convergence.
* **Action:** High-contrast Teal lines moving from the periphery toward a central axis (1.5 to 0 scale).
* **Goal:** Grounding via "Inward Flow" to bring the user back to a stable baseline.

### **05. Circuit Breaker**
* **Technique:** Sensory Overload / Neuro-Reset.
* **Action:** 20-second Red/White full-screen strobe synchronized with a 4px Vagal Pulse border.
* **Safety Gate:** Requires explicit acknowledgment of a "Kinetic Override" warning before activation.

## SAFETY PROTOCOLS & EXIT STRATEGY

### **Universal Termination**
Every module contains a persistent **"TERMINATE [PHASE]"** button in the top-right corner.
* **Direct Exit:** (Triage, Ocular Sweep) Returns the user immediately to the Dashboard.
* **Safety Landing:** (White Surge, Circuit Breaker) Termination redirects the user to **Axial Stabilize** first. This ensures a "soft landing" and prevents the biological jarring of a sudden stop.

### **Emergency Warning**
> **WARNING:** The Circuit Breaker module utilizes high-frequency light stimulation. It is strictly prohibited for users with photosensitive epilepsy, history of seizures, or light-triggered migraines.
